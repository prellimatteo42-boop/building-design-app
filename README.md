# Building Design

A BIM application that runs in the browser. Open it at the address of this site; nothing to install.

This repository holds the built site. Its source is in `building-design-source.zip`, under the AGPL-3.0 licence (`LICENSE.txt`).

The assistant needs a Claude API key of your own; it stays in your browser and is sent only to Anthropic.
